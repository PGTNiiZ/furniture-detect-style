# การนำโมเดลไปใช้กับภาพห้องจริง

ส่วนนี้ทดลองนำโมเดลที่ฝึกเสร็จแล้วไปใช้กับภาพห้องจริงที่ไม่อยู่ในชุดข้อมูลฝึก เพื่อดูว่าเมื่อใช้งานจริงระบบระบุ **ประเภท (type)** และ **สไตล์ (style)** ของเฟอร์นิเจอร์แต่ละชิ้นในภาพได้อย่างไร

## ขั้นตอนการทำงาน

ภาพห้องหนึ่งภาพมีเฟอร์นิเจอร์หลายชิ้น จึงทำงานเป็น 2 ขั้น

1. **Detector (YOLOv8n pretrained บน COCO)** หาตำแหน่งเฟอร์นิเจอร์และวาด bounding box แล้วแปลง label ของ COCO เป็นหมวดของโปรเจกต์ (`couch→sofa`, `dining table→table`, `chair→chair`, `bed→bed`) ส่วน label อื่น เช่น `potted plant` จะไม่ถูกส่งไปจำแนก
2. **Classifier ของโปรเจกต์ (DenseNet121, เงื่อนไข C6, ชุดข้อมูล furniture-v3-style5, seed 123)** รับภาพที่ crop จากแต่ละกรอบ แล้วทำนายพร้อมกันทั้ง type และ style (5 สไตล์) ด้วย head สองหัวบน backbone เดียวกัน

ความหมายของสีกรอบ
- **เขียว**: detector และ classifier เห็นตรงกันว่าเป็นประเภทเดียวกัน
- **แดง**: detector และ classifier ทำนายประเภทไม่ตรงกัน (disagreement)
- **เทา**: วัตถุที่ไม่ใช่เฟอร์นิเจอร์ในขอบเขตของโมเดล

## สรุปผลการใช้งานจริง

**สิ่งที่ทำได้ดี**
- เมื่อ crop มีเฟอร์นิเจอร์ชิ้นเดียวและเห็นชัด เช่น โซฟาในภาพที่ 1 หรือเก้าอี้ในภาพที่ 2 โมเดลทายประเภทถูกและมั่นใจสูง (0.73–1.00) สอดคล้องกับ type accuracy บน real-source test ที่ 0.84
- ระบบกรองวัตถุที่ไม่ใช่เฟอร์นิเจอร์ เช่น ต้นไม้ ออกได้ถูกต้อง
- การเทียบผลของ detector กับ classifier (กรอบสีแดง) ช่วยชี้จุดที่น่าสงสัยให้คนตรวจได้ โดยทั้ง 2 ชิ้นที่ทายผิดในภาพที่ 2 ถูกระบบทำเครื่องหมายไว้แล้ว

**ข้อจำกัด**
1. **สไตล์ยังไม่น่าเชื่อถือ:** confidence ส่วนใหญ่อยู่ที่ 0.4–0.5 และอันดับ 1 กับ 2 มักใกล้กัน ตรงกับ macro-F1 ของ style บน real-source test ที่ได้เพียง 0.29 อีกทั้งสไตล์เป็นเรื่องที่ตีความได้หลายแบบโดยธรรมชาติ ควรแสดงผล top-2 หรือ top-3 แทนการให้คำตอบเดียว
2. **Detector เป็นคอขวด:** ใช้ YOLOv8n ที่ฝึกบน COCO โดยไม่ได้ฝึกเพิ่ม จึงพลาดเฟอร์นิเจอร์รูปทรงแปลก (โต๊ะตอไม้) ให้กรอบซ้ำ (โต๊ะ #1 กับ #4) และตรวจจับผิด (#3)
3. **ฉากที่มีวัตถุซ้อนกัน:** crop ของวัตถุที่ถูกบังจะมีเฟอร์นิเจอร์ชิ้นอื่นปนอยู่ classifier ซึ่งฝึกจากภาพสินค้าชิ้นเดียวจึงตอบตามชิ้นที่เด่นกว่า
4. **แสงผิดปกติ:** ภาพที่ 2 มีแสงโทนส้มจัด ซึ่งต่างจากภาพในชุดฝึกมาก ทำให้ความมั่นใจด้านสไตล์ต่ำลง
5. **ยังไม่ใช่การประเมินเชิงปริมาณ:** ภาพห้องยังไม่มี annotation ที่ผ่านการตรวจจากคน จึงเป็นการสาธิตเชิงคุณภาพจาก 2 ภาพเท่านั้น ส่วน confidence เป็นค่า softmax ที่ยังไม่ได้ calibrate

**แนวทางปรับปรุง:** ฝึก detector ด้วยภาพห้องที่มี annotation เฟอร์นิเจอร์, ใช้ NMS ข้ามคลาสเพื่อตัดกรอบซ้ำ, เพิ่ม augmentation ด้านแสงและสี, และเพิ่มภาพห้องจริงที่มี label สไตล์ในชุดฝึก
